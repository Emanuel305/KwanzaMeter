KwanzaMeter

KwanzaMeter é uma aplicação de gestão financeira pessoal desenvolvida com Python e Flet, criada para ajudar os utilizadores a controlar melhor o seu dinheiro em Kwanza (Kz).

A aplicação permite:

Registar receitas e despesas;
Organizar transações por categorias;
Visualizar estatísticas e o resumo financeiro;
Criar e acompanhar orçamentos;
Receber notificações quando um orçamento é ultrapassado;
Definir e acompanhar metas financeiras;
Gerar relatórios financeiros em PDF;
Consultar taxas de câmbio;
Utilizar a Kamba IA, um assistente financeiro integrado;
Executar a aplicação em dispositivos Android.
Tecnologias

Python · Flet · FastAPI · Groq AI · ReportLab · JSON · REST API

A aplicação utiliza um backend FastAPI para a Kamba IA, mantendo a comunicação com os serviços de inteligência artificial separada da aplicação principal.

O KwanzaMeter encontra-se atualmente em fase Beta e continua em desenvolvimento, com foco em melhorar a gestão financeira pessoal através de uma interface simples, moderna e inteligente.
